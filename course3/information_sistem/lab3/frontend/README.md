# 🪄 Магический мир книжных существ - Frontend

React приложение с TypeScript для управления магическими существами, городами и кольцами.

## 🚀 Запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите приложение в режиме разработки:
```bash
npm run dev
```

3. Откройте браузер по адресу: http://localhost:3000

## 🏗️ Сборка

Для создания production сборки:
```bash
npm run build
```

## 🎯 Функциональность

- **Управление существами**: просмотр, создание, редактирование, удаление
- **Управление городами**: просмотр, создание, редактирование, удаление
- **Современный UI**: адаптивный дизайн с градиентами и анимациями
- **TypeScript**: полная типизация для безопасности кода
- **API интеграция**: взаимодействие с Java бэкендом

## 🔧 Технологии

- React 18
- TypeScript
- Vite
- Axios
- CSS3 с градиентами и анимациями

## 🌐 API

Приложение настроено для работы с Java бэкендом на порту 8080. Прокси настроен в `vite.config.ts` для перенаправления запросов `/api/*` на бэкенд.
